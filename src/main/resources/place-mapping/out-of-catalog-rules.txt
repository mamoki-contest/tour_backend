# 카탈로그 대상이 아닌 장소를 가려내는 사전 (#72)
#
# 미매칭 이름을 OUT_OF_CATALOG / NAME_VARIANT / UNKNOWN 으로 나눌 때, OUT_OF_CATALOG
# 판정에만 쓴다. 이 사전을 코드 상수로 두지 않는 것은, 실제 데이터를 보고 고치는 일이
# 잦을 규칙이기 때문이다. 고칠 때 자바를 건드리지 않아도 되고 무엇이 바뀌었는지가
# 파일 하나의 diff 로 남는다.
#
#   [category-group]  카카오 category_group_code 가 이 목록에 있어야 한다
#   [category-name]   카카오 category_name 이 이 조각을 담고 있어야 한다
#   [name-suffix]     원천 이름이 이 말로 끝나야 한다 (표기 정규화 후 비교)
#
# 카테고리 쪽과 이름 접미어 쪽이 **둘 다** 맞을 때만 OUT_OF_CATALOG 다. 한쪽만이면
# UNKNOWN 으로 남겨 분모에 그대로 둔다. 분모를 줄이는 판정은 틀려도 에러가 나지 않고
# 매칭률만 좋아 보인다.
#
# 접미어 규칙에는 한 겹이 더 있다. **강원 카탈로그에 그 말이 든 장소가 하나라도 있으면
# 그 실행에서 그 규칙을 끈다.** 카탈로그가 담고 있는 종류를 "카탈로그 대상이 아니다"
# 라고 말할 수는 없기 때문이다. 실제로 골프장·리조트·휴게소·영화관은 KorService2 가
# 레포츠·숙박·문화시설로 담고 있어(2026-09-20 강원 4,741곳 기준 골프 25곳, 리조트 55곳)
# 아래에 적혀 있어도 꺼진다. 꺼진 규칙은 배치 로그에 이름과 카탈로그 건수로 남는다.
#
# 그래도 지워 두지 않는 것은, 카탈로그가 바뀌면 판단도 바뀌어야 하기 때문이다.
# 여기서 지우면 다음 사람은 이 종류를 한 번도 검토하지 않은 것과 구별할 수 없다.

[category-group]
# 카카오가 쓰는 18개 코드 중, 관광공사 카탈로그(관광지·레포츠·숙박·음식점·쇼핑·
# 문화시설·축제·여행코스)에 대응이 없는 것만 적는다. 음식점(FD6)·카페(CE7)·숙박(AD5)·
# 관광명소(AT4)·문화시설(CT1)·대형마트(MT1)는 카탈로그가 담으므로 적지 않는다.
