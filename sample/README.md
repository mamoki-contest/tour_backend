# sample

외부에서 내려받은 원본 데이터 파일을 두는 곳입니다.
TMAP 검색순위 임포터가 이 파일들로 동작을 검증하므로 저장소에서 함께 추적합니다.

## TMAP 지역별 관광지 검색순위 원본

- 출처: 한국관광 데이터랩 `지역별 분석 > 지역별 현황 > 인기관광지 현황`
- 원천 조회기간: 202508-202607
- 강원 18개 시·군을 각각 내려받은 zip 18개

zip 하나에 세대별 CSV 6종(전체/20/30/40/50/60대)이 들어 있습니다.

PRD v4 기준 이 데이터는 목록 정렬의 주 지표가 아니라 `시·군 내 TMAP 검색 N위`
보조 근거입니다. 정렬 주 지표는 네이버 블로그 검색 결과 수입니다.
지역과 원천 조회기간은 CSV 안에 없고 zip 파일명에만 있습니다.

```
{타임스탬프}_{시도}+{시군}_{시작월}-{종료월}_데이터랩_다운로드.zip
```

CSV 형식은 헤더 `순위,관광지ID,관심지점명,구분,연령대,비율`, UTF-8 with BOM,
LF 줄끝이며 각 데이터 행 끝에 탭 문자가 붙어 있습니다.

## 주의

데이터랩 데이터에는 출처 표시 등 이용조건이 따릅니다.
저장소가 공개되어 있으므로 재배포 조건을 확인하고 사용하세요.

## 주요관광지점 입장객통계

`주요관광지점 입장객(2004.07 이후)_*.xls` 는 관광지식정보시스템에서 받은 공식 통계표다.

- 출처: https://know.tour.go.kr/stat/visitStatDis/table.do
- 받는 조건: 기간 `월별`, 지역 `강원특별자치도`, 구분 `전체`
- 내려받을 때 **셀 병합을 해제**한다. 병합된 채로 받으면 행이 어긋난다

공표는 분기 단위라 매달 새 자료가 나오지 않는다. 새 분기 잠정치나 연간 확정치가 공표되면
다시 받아 적재한다. 확정치는 이듬해 4월에 공표된다.

파일에는 아직 공표되지 않은 달의 열이 미리 만들어져 비어 있고, 잠정 집계 중인 달은 일부
시·군만 제출되어 있다. 임포터가 **모든 시·군에 값이 있는 마지막 월**을 공표월로 고른다.
